Comment ça marche

Trois gestes de votre part, le reste est pour nous

Vous dites combien vous avez, vous notez ce que vous dépensez, vous regardez le chiffre. C'est tout.

Gardez un œil sur vos dépenses

Vérifiez combien vous pouvez encore dépenser, grâce à des compteurs simples et intuitifs qui se mettent à jour en temps réel.

Le budget, c'est vous qui le décidez

Vous fixez le budget disponible pour la période de votre choix. Les calculs — jour après jour, semaine après semaine — c'est iCanSaveit qui s'en occupe.

Indulgent envers les oublis

Vous avez oublié de noter une dépense ? Pas de problème : vous pouvez toujours ajuster les comptes plus tard.

Ce qu'il y a sous le capot

Un calcul, refait chaque jour...

Vous avez 900 € pour 30 jours : le plafond du jour est de 30 €. Vous dépensez 12 € au déjeuner ? Ce qu'il reste — 888 € — est reparti sur les 29 jours restants. Le plafond de demain n'est pas décidé à l'avance : il naît de ce que vous avez dépensé jusqu'ici.

01

Vous dites combien vous avez et pour combien de temps ça doit durer.

02

Chaque dépense est aussitôt retirée du total.

03

Ce qu'il reste est reparti sur les jours restants, à chaque fois.

...pour voir où vous allez

iCanSaveit regarde combien vous avez dépensé en moyenne par jour depuis le début, et le projette sur les jours restants : vous savez ainsi, dès aujourd'hui, s'il vous restera quelque chose en fin de mois ou si vous dépassez le budget.
